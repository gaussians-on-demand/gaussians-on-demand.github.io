Abstract

Splat-based radiance fields have rapidly diversified in primitive type, kernel support, and appearance parameterization. This diversity makes compression difficult: most codecs are single-rate, requiring a separately optimized model for each target bitrate, while progressive codecs remain tied to representation-specific assumptions that do not transfer across backbones. We introduce GoDe (Gaussians on Demand), a progressive compression framework whose central contribution is backbone agnosticism: it reorganizes any trained differentiable splat representation into a single scalable bitstream without modifying the backbone or re-deriving the compression structure for each new primitive type. GoDe builds a nested level-of-detail hierarchy via masked-gradient importance ranking, refines all levels with one quantization-aware fine-tuning stage, and stores the base layer and enhancement layers as progressive chunks compressed with shared entropy dictionaries. Any decoded prefix is directly renderable, so one training pipeline provides multiple rate–distortion operating points without per-rate retraining. Across five heterogeneous backbones and three standard benchmarks, GoDe achieves competitive rate–distortion performance while enabling faster rendering and substantially faster progressive decoding than existing methods.

Method

Three stages, applied to an already trained model. They need only a differentiable renderer and a serializable parameterization.

Swipe sideways to see all three stages.

1Hierarchy

Primitives are ranked by their gradient norms, each parameter group normalized, and the least important are masked out level by level, recomputing gradients after every step. Coarser levels are strict subsets of finer ones. Building eight levels takes 1–2 minutes.

2One fine-tuning

All levels share one set of parameters. Each iteration samples a level and a view and renders that level with simulated quantization (float16 geometry, int8 appearance), so the cost does not grow with the number of levels.

3Progressive coding

The base layer and each enhancement layer are compressed as independent chunks with shared Zstandard dictionaries. Decoding a level is decoding and concatenating its chunks; an opacity ramp makes switching smooth.

Training and decoding time

Non-scalable codecs train once per rate; GoDe trains once for all of them. Decoding is cumulative over the levels needed for each rate.

One pipeline, five backbones

GoDe treats primitives as atomic units: it never looks inside them. The same procedure runs on representations that differ in primitive type, kernel, and appearance model.
